# Crow Translate Offline Wiki

本项目把“一次手工部署”整理为可复现的用户级安装流程。

1. **[安装](Installation.md)**：检查条件、一键安装、使用代理、复制缓存离线重装。
2. **[实现原理](Architecture.md)**：为什么 Crow 需要本地引擎，怎样确保日常请求留在本机。
3. **[故障排查](Troubleshooting.md)**：快捷键、PDF 选区、端口、namespace 和模型问题。
4. **[测试与性能](Verification.md)**：真实调用结果、测试方法与尚未验证的部分。
5. **[维护与回滚](Maintenance.md)**：目录结构、日志、版本更新、卸载和备份。

这些页面随代码版本一起保存在 `docs/`。即使 GitHub Wiki 不可用，下载源码包也能离线阅读。
公开仓库的 Wiki 使用相同内容，文档源以仓库中的 `docs/` 为准。
